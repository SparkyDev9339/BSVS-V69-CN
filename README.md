> **BSVS CN v69** — экспериментальный приватный сервер для китайского клиента Brawl Stars версии **69**. Мы публикуем исходный код, чтобы разработчики могли изучать протокол, улучшать поддержку клиента и вместе развивать проект.
>
> Это **неофициальный фанатский проект**, не связанный с Supercell, Tencent или разработчиками оригинальной игры.

## 🚀 Что есть на сервере

- **Подключение клиента CN v69.** Обработка пакета входа, проверка версии клиента (`ClientMajor = 69`), отправка данных авторизации и главного экрана.
- **Аккаунты и сохранение прогресса профиля.** Автоматическое создание ID и токена, повторный вход по токену, хранение аккаунта и ника в **SQLite**.
- **Смена ника.** Проверка имени, серверная команда изменения ника и сохранение результата между входами.
- **Работающий главный экран.** Формирование пакета `OwnHomeDataMessage` с данными профиля и лобби для клиента v69.
- **Бойцы.** Формирование списка доступных бойцов на основе CSV-данных v69; в текущей конфигурации им назначается **11-й уровень силы**.
- **Косметика.** Передача доступных скинов, иконок профиля, эмоций и связанных косметических элементов из таблиц ресурсов.
- **Способности и экипировка.** Данные о гаджетах, звёздных силах, гиперзарядах, дополнительных картах экипировки и снаряжении бойцов.
- **Ресурсы для демонстрационного аккаунта.** Преднастроенные значения валют и элементов прогресса (в интерфейсе можно увидеть, например, **99 999** монет и гемов).
- **Система событий и конфигураций.** В проекте есть данные событий и магазина в JSON, а также код формирования игровых конфигураций.
- **Сетевое ядро на Python.** TCP-подключения, асинхронная обработка через `asyncio` (по умолчанию), альтернативный потоковый режим, ограничения размеров пакетов и таймауты.
- **Инструменты разработки.** Обработка и сериализация игровых пакетов, настройки логирования/дампа пакетов, тесты и отдельная утилита для подготовки контент-обновлений.

> **Важно:** отображение кнопок «Играть», «Магазин», «Клуб», «Квесты» и других разделов **не означает**, что их серверная логика полностью реализована. Текущий релиз прежде всего демонстрирует подключение, аккаунты и данные лобби. Полноценный матчмейкинг, онлайн-бои, покупки и социальные функции **не заявляются как работающие**.

## 🛠️ Быстрый запуск

**Понадобится:** Python **3.10+**, исходники проекта и совместимый клиент **Brawl Stars CN v69**.

1. Скачайте репозиторий и перейдите в его корневую папку (там, где находится `Core.py`).
2. При необходимости измените параметры в `Configuration.py`.
3. Запустите сервер:

   ```bash
   python Core.py
   ```

4. Сервер по умолчанию слушает **TCP-порт `9339`** на адресе `0.0.0.0`.
5. Для подключения направьте **совместимый клиент CN v69** на IP-адрес своего сервера и порт `9339`. Настройка клиента зависит от используемой сборки и в этот репозиторий не входит.

**Тесты:**

```bash
python -m unittest discover -s tests -v
```

*В предоставленной версии исходников выполнены 9 тестов: все прошли успешно. Это не заменяет проверку всех экранов и функций в игре.*

## ⚙️ Конфигурация

Основные параметры находятся в **`Configuration.py`**:

| Параметр | Назначение |
| --- | --- |
| `UseAsyncServer` | Использовать асинхронный сервер (`True` по умолчанию). |
| `DisableNagle` | Включить `TCP_NODELAY` для уменьшения задержек. |
| `PrintEnabled` | Выводить информацию об обработанных сообщениях. |
| `DumpPacket` | Сохранять дампы пакетов для отладки. |
| `ReadTimeout` / `WriteTimeout` | Таймауты сетевых операций. |
| `IdleTimeout` | Время ожидания активности клиента. |
| `MaxPacketSize` | Максимально допустимый размер входящего пакета. |

> В текущем `Core.py` порт `9339` задан напрямую. В архиве также есть `settings.json`, но основной процесс при запуске читает настройки из `Configuration.py`, а не из этого JSON-файла.

```text

├── Core.py                      # Точка входа

├── settings.json                # Дополнительный файл настроек
├── Classes/
│   ├── AsyncServerConnection.py # Асинхронные подключения
│   ├── ByteStream.py            # Чтение / запись данных протокола
│   ├── Logic/                   # Игровые данные и фабрика сообщений
│   ├── Packets/                 # Клиентские и серверные пакеты
│   └── Files/assets/           # CSV-данные v69 и локализации

│   ├── DatabaseHandler.py       # Работа с аккаунтами
│   └── Files/                   # Локальная SQLite-база
├── JSON/                        # События и данные предложений
├── ContentUpdater/             # Утилиты контент-обновлений
├── tests/                       # Автоматизированные тесты
├── assets/
│   └── screenshot.png           # Скриншот для README
└── README.md
```
