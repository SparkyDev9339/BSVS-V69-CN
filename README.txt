BSVS CN v69 — первый open-source релиз BSVS для китайской версии
Brawl Stars (CN v69). Это экспериментальный приватный сервер на
Python с открытыми исходниками для изучения, улучшения и развития
сообществом.

Проект неофициальный и не связан с Supercell или Tencent.

экранов не означает, что все эти возможности реализованы на сервере.
Полноценные онлайн-бои, матчмейкинг, покупки, клубы и социальные
функции пока НЕ заявляются как работающие.

КАК ЗАПУСТИТЬ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Установите Python 3.10+.
2. Откройте корневую папку с файлом Core.py.
3. При необходимости настройте Configuration.py.
4. Запустите команду:

   python Core.py

5. По умолчанию сервер слушает TCP 0.0.0.0:9339.
6. Направьте совместимый клиент Brawl Stars CN v69 на IP и порт
   своего сервера. Порядок настройки зависит от сборки клиента.

Для запуска тестов:

   python -m unittest discover -s tests -v

Проверка предоставленных исходников: 9 тестов прошли успешно.

Основной файл: Configuration.py

- UseAsyncServer     — асинхронный режим сервера (по умолчанию True).
- DisableNagle       — TCP_NODELAY для снижения задержек.
- PrintEnabled       — вывод информации об игровых сообщениях.
- DumpPacket         — запись пакетов для диагностики.
- ReadTimeout        — таймаут чтения.
- WriteTimeout       — таймаут записи.
- IdleTimeout        — таймаут неактивного соединения.
- MaxPacketSize      — ограничение размера принимаемого пакета.

Порт 9339 в Core.py прописан напрямую. settings.json присутствует,
но основной процесс при запуске использует Configuration.py.
