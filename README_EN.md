## About the Project

BSVS is built for **Brawl Stars China** enthusiasts who want to explore the game's server-side architecture and experiment with their own builds. The server is written in **Python** and targets compatibility with the **CN v69** client.

In the current release, a compatible client can connect to the server, access a player profile, and load the home screen. The source code is available to study, extend, and improve through community contributions.

This is the **first open-source release of BSVS CN v69**. Contributions are welcome!

## Getting Started

**Requirements:** Python 3.10+ and a compatible Brawl Stars CN v69 client.

1. Download the project source code.
2. Open a terminal in the folder containing `Core.py`.
3. Start the server:

   ```bash
   python Core.py
   ```

4. Point a compatible client to your server's IP address and TCP port `9339`.

The client connection setup depends on the specific client build you use.
